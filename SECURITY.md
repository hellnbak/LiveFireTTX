# Security Policy

LiveFireTTX is a safe simulation framework for tabletop and resilience exercises.

## Reporting security issues

Please report security issues privately to the project owner before public disclosure.

## Safety expectations

Do not submit or request features that add malware, credential theft, exploit chains, persistence, evasion, anti-forensics, destructive payloads, or unauthorized access capability.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| 0.x | No |

Security fixes target the latest v1.x release. Operators should upgrade generated
exercise packages when a controller or safety-boundary fix is published.
